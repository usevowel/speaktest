# Font Credits

This project uses the following fonts:

## OCR-A

- **File**: `client/public/OCR-A_Regular.otf`
- **Usage**: Logo/branding font for "vowel" text in the header
- **License**: Public Domain (originally designed for ANSI standard in 1966)
- **Source**: The OCR-A typeface is a public domain font commonly used for optical character recognition systems.

## Russo One

- **Usage**: Display font loaded via Google Fonts
- **License**: SIL Open Font License (OFL) - Free for commercial use
- **Source**: [Google Fonts](https://fonts.google.com/specimen/Russo+One)
- **Designer**: Jovanny Lemonad

## System Fonts

The application also uses system fonts as fallbacks:

- **UI Font Stack**: System UI fonts (varies by platform)
- **Monospace**: `ui-monospace, SFMono-Regular, "SF Mono", Menlo, Consolas, "Liberation Mono", monospace`

---

*Note: Previously included local font files for Roboto, Syne, Audiowide, Genos, and Orbitron have been removed as they were not actively used in the application.*
