## Multi Lingual

- vowel is capable of instant multi-lingual interaction 

(Just start speaking one of our supported languages 
and vowel will respond in kind lingually 
but interact with the website in the source language 
in this case English .. this is important for navigation, filtering etc.) 

- If you are not a polyglot please try our Multi Language Tool

Open this link on your phone

[vowel | test](https://speaktest.vowel.to/)



- First Tab - soundboard with phrases for the demo you are using
- Second Tab - change tgt (target) language to have the tool speak the phrases in a selected language
- Ear Icon - in upper right .. click to activate, it will listen to the language interaction
  and give you a translation in the Src (source language) 

Thank you for taking time to explore our demos! 

Here are some quick facts about the vowel solution:

- Low latency, yet highly intelligent responses
- Fully interruptable
- Multi Lingual (see below)
- Bulk of website "functional coverage" using AI tooling (i.e. [Claude Agent Skills](https://claude.com/blog/skills) )
- Fully compatible with [OpenAPI Realtime API](https://platform.openai.com/docs/guides/realtime)
- All configuration is client side  (i.e. [Ephemeral Tokens](https://en.wikipedia.org/wiki/Ephemeral_key), Client side [context aware actions](https://docs.vowel.to/) )
